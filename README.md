# Love Connect

Love Connect is a modern Android app built with Kotlin and Jetpack Compose for Android 15 support.

Features:
- Six-digit pairing code
- Private chat between two consenting users
- Optional location sharing with clear permission prompts
- Camera sharing only after visible approval
- Battery and online status
- Disconnect and revoke access anytime
- Safe, consent-first design without hidden monitoring or unauthorized access

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android 15 target support

## Run locally
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or connected device.

## Notes
This project is intentionally consent-first and privacy-safe. All permission flows are clearly explained and user-controlled.
